# 🏦 Customer Loan Conversion Prediction

An end-to-end machine learning project for predicting whether an existing bank customer is likely to accept a personal loan.

The project includes **Exploratory Data Analysis, feature selection, model comparison, stratified cross-validation, Optuna hyperparameter tuning, classification-threshold optimization, and Streamlit deployment**.
